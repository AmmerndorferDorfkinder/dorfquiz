# Ammerndorfer Dorfkinder Dorfquiz

Dies ist eine vorbereitete Projektkopie. Die bisherige Arbeitskopie bleibt im Ordner `Dorfquiz Ammerndorf/dorfquiz` unverändert.

## Neue Dateien ablegen

- Neue Stationsaudios gehoeren in `assets/audio/`. Die erwarteten Namen und Stationszuordnungen stehen in `assets/audio/README.md`.
- Zusaetzliche Seitenbilder gehoeren in `assets/images/`. Das Vereinslogo liegt dort bereits.
- Die neun druckbaren Stations-QR-Seiten liegen im Projektstamm unter `station-qr-1.html` bis `station-qr-9.html`; die Vorlage ist `station-qr-template.html`.

## Vor einer Veroeffentlichung

Die neun QR-Druckseiten zeigen auf `https://ammerndorferdorfkinder.github.io/dorfquiz/` und verwenden Stationsnamen statt Nummern oder Schluesseln. Erst nach Veroeffentlichung testen und drucken. Die Scanfolge wird nur im Browser als Spielregel geprueft; Stationsinhalte sind nicht zugriffsgeschuetzt.
